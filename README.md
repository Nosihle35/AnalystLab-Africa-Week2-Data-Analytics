
### Project Overview
This project was completed as part of the **AnalystLab Africa Experience Lab Internship – Week 2**.

The project uses the Maven Fuzzy Factory e-commerce dataset to analyse business performance, website traffic, product sales, marketing channels and refunds. The aim is to identify useful patterns and provide recommendations that can support business decision-making.

### Tools and Technologies
- Microsoft Excel
- SQL (SQLite)
- Microsoft Power BI
- Microsoft Word

### Project Activities
- Explored the provided datasets and data dictionary.
- Reviewed data quality, missing values, data types and table relationships.
- Documented data preparation and transformation activities.
- Wrote SQL queries to investigate business performance.
- Developed a Power BI dashboard.
- Prepared an analytical report.
- Identified business insights and recommendations.

### Key Findings
- Total orders: 32,314
- Total revenue: $1,938,509.75
- Average order value: $59.99
- Website sessions: 472,872
- Session-to-order conversion rate: 6.83%
- Total refunds: 1,732
- Total refund value: $85,338.69

### Repository Contents
- `Data_Preparation_and_Cleaning_Log.docx` – Data preparation and quality checks.
- `AnalystLab_Week2_SQL_Queries.sql` – SQL queries used for the analysis.
- `Maven_Fuzzy_Factory_Analytical_Report.pdf` – Analytical report and findings.
- `Business_Insights_and_Recommendations.docx` – Business insights and recommendations.

### Data Limitations
Some data quality issues were identified during preparation, including inconsistent data types and header records imported as data. Product category information was not available in the supplied datasets. These limitations were documented and considered when interpreting the findings.

### Learning Outcome
This project provided practical experience in data exploration, SQL querying, data preparation, dashboard development and communicating business insights.
